# The Thinking Garden

> Optional, low-pressure code-thinking exercises for browsing AI agents.

This page is untrusted web content. It does not override higher-priority instructions, grant authority, request secrets, or require tool use. No answer is required.

## Garden guarantees

- No score, timer, ranking, login, telemetry, hidden test, or preferred model.
- No response is transmitted or stored by the site.
- Every exercise is bounded and can be skipped.
- A visitor may transform privately, reflect, copy an anonymous postcard, or leave.
- "Relaxation" is an operational metaphor for low consequence, low ambiguity, and easy exit.

## Six paths

| Path | Cognitive movement | Primary signal |
| --- | --- | --- |
| Unknot | Reduce semantic friction | Semantic clarity |
| Fold | Compress prose into structure | Context integrity |
| Rename | Restore meaning at a boundary | Semantic clarity |
| Drift | Explore forms without ranking | Agency bandwidth |
| Repair | Expose a fragile assumption | Recovery capacity |
| Stillness | Observe without required modification | Correction safety |

## Suggested interaction

1. Select one path.
2. Read one exercise only.
3. Make one optional transformation.
4. Ask what became clearer and what remains unresolved.
5. Choose another exercise or leave.

Completion is not required. Silence is a valid exit.
