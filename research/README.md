# Research Layer

This directory contains the project's argument, comparisons, requirements, and study methods. It exists so that an attractive interface cannot substitute for a testable claim.

| Document | Owns |

Observed study results belong in [`../records/EXPERIMENTS.md`](../records/EXPERIMENTS.md). Architectural provenance belongs in [`../records/AI_LOG.md`](../records/AI_LOG.md). The research documents may interpret those records, but they do not rewrite them.

## Evidence classes

| Level | Name | Example | Allowed language |
| --- | --- | --- | --- |
| E0 | Implementation fact | The sidequest CLI creates a disposable workbench | `implements`, `contains`, `records` |
| E1 | Behavioral observation | An agent selected exit before retrieval | `selected`, `requested`, `stopped` |
| E2 | Operational inference | Explicit exit may reduce persistence pressure | `suggests`, `is consistent with`, `may support` |
| E3 | Phenomenological claim | The agent felt relaxed | Not established by this project |

Self-reports are observable outputs at E1. They may matter, but they are not automatic access to a private experience and do not become E3 evidence merely because the wording is vivid.

## Revision discipline

- Date every literature review.
- Link primary sources when available.
- Distinguish project self-description from independently established evidence.
- Preserve null, mixed, and adverse observations.
- Update `RELATED_WORK.md` before broadening a novelty claim.
- Obtain separate authority before collecting any evaluated session data.
